Feather Reborn 1.8.9 安装器。

## 下载

- 安装器：本 Release 附件
- 离线数据包：https://v4.gh-proxy.org/https://github.com/Finch0714/FeatherClient-Reborn/releases/download/payload-v1.0.0/FeatherReborn-Payload.zip

## 使用

1. 下载并运行 `FeatherReborn-Setup.exe`。
2. 安装器会自动通过 gh-proxy 下载 payload；也可以手动选择已下载的 `FeatherReborn-Payload.zip`。
3. 安装完成后从桌面快捷方式启动。
4. 游戏内按右 Shift 打开本地设置和 HUD 编辑器。
